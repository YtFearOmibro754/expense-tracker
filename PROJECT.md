# Expense Tracker - GitHub Repository

Welcome to the Expense Tracker project! This is a simple, accessible, and fully functional expense tracking solution.

## 📋 Overview

This project provides an **Excel-based expense tracker** that requires minimal setup and works with any spreadsheet application.

## 🚀 Quick Start (Choose One)

### Option 1: 30-Second Setup (Recommended)
```bash
pip install openpyxl && python3 create_tracker.py
```
Then open `Expense_Tracker.xlsx` and start using it!

### Option 2: Read First
1. See **QUICK_START.md** for a walkthrough
2. See **INSTALL.md** for detailed installation steps
3. See **README.md** for complete feature list

## 📁 What's Included

- `create_tracker.py` - Main script that generates your Excel file
- `Expense_Tracker.xlsx` - Your ready-to-use expense tracker (generated)
- `README.md` - Full documentation
- `QUICK_START.md` - User-friendly quick start guide

- `package.json` - Node.js dependencies (for future web version)

## ✨ Key Features

✅ **Works Offline** - No internet needed  
✅ **No Installation Required** - Just Python (pre-installed on most systems)  
✅ **Accessible Format** - Works with Excel, Google Sheets, LibreOffice  
✅ **Professional Design** - Color-coded, formatted, easy to read  
✅ **Auto-Calculating** - Totals update automatically  
✅ **Fully Customizable** - Add categories, modify columns, extend as needed  
✅ **Zero Learning Curve** - If you've used a spreadsheet, you can use this

- Total expenses (auto-calculated)

- Pre-defined categories
- Easy to customize
- Reference list

## ❓ FAQ

**Q: Do I need to pay for this?**  
A: No, it's completely free and open-source.

**Q: Can I use this on my phone?**  
A: Yes! Upload to Google Sheets or use OnlyOffice mobile app.

**Q: Will my data be stored in the cloud?**  
A: Only if you upload to Google Sheets or another cloud service. Locally it's just a file.

**Q: Can I add more columns?**  
A: Absolutely! It's just a spreadsheet - fully customizable.

**Q: Is my data secure?**  
A: Your local file is as secure as your computer. Use cloud services with caution and proper security.

**Q: How often should I back up?**  
A: Daily or weekly depending on how often you add expenses.
